# AgentSquad

Reusable Squad team templates for projects under `~/Code`.

## Uno Platform team template

`templates/uno-platform-team/` contains reusable roster, routing, agent charters,
model preferences, and review policies for an Agent team that builds Uno Platform apps with high confidence.

For a new project:

1. Run `squad init` in the project to create its own `.squad/` state and
   Squad-managed templates.
2. Copy the contents of `templates/uno-platform-team/.squad/` into that
   project's `.squad/`, reviewing any existing files before replacing them.
3. Replace template placeholders in `team.md` and `casting/registry.json`.
4. Create fresh per-project histories, decisions, and logs; do not reuse those
   from another project.
5. Copy the template `.gitattributes` entries into the project root if they
   are not already present.
6. Copy `.copilot/mcp-config.json` into the project root to enable the Uno
   Platform docs MCP (`uno`) and App MCP (`uno-app`) servers the charters use.
7. Optionally replace `.squad/config.json` with a profile from
   `model-profiles/` (`balanced`, `anthropic`, `openai`, or `economy`).

## Models

Each charter names one `Preferred` model that Squad reads, plus a
`Model Options` table listing OpenAI, Anthropic, and Google choices per task.
`.squad/model-policy.md` defines fallback chains, provider-pinned chains, and
the cross-family review rule. Model IDs use GitHub Copilot's dotted form
(for example `claude-opus-5.5`); check what your plan offers with `/model`
in `copilot`.

The package intentionally excludes agent histories, decisions, logs, audit
trails, screenshots, and other project-specific runtime data. Squad-managed
files in `.squad/templates/` should be generated by `squad init` and maintained
by the Squad CLI rather than copied from a project.
