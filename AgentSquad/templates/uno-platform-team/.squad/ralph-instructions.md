# Ralph Instructions

> Optional starter instructions for `squad watch --execute`. Review the trust
> implications before enabling autonomous execution.

## Issue Selection

Work on open, unblocked, unassigned issues labeled `squad` or `squad:{member}`.
Skip issues assigned to a human, blocked, or marked `status:on-hold`.

## Post-Task Actions

Add project-specific notifications or post-task hooks here only after reviewing
the tools and permissions the spawned session will have.

## Escalation

If blocked on an issue, comment with the reason, add `status:blocked` if that
label exists in the project's tracker, and continue to the next actionable
item. Do not expose secrets or other sensitive project data.
